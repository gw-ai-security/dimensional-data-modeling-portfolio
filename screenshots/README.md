# Screenshot Evidence

Screenshots will be added as the capstone is implemented.

Recommended structure:

```text
screenshots/
├── before/
├── dimensions/
├── facts/
├── relationships/
├── validation/
└── security/
```

## Rules

- capture evidence that proves a modeling decision or validation result
- prefer readable crops over full-screen clutter
- do not include credentials, personal email addresses or confidential data
- name files by purpose rather than `Screenshot1.png`
- accompany important screenshots with explanatory text in the relevant documentation
