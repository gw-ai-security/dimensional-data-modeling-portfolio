## Source hierarchy

For course-specific claims, this repository follows the supplied transcripts. General modeling knowledge is not silently substituted for the course's terminology, sequence or recommendations.

The theory documentation is intentionally separated from implementation evidence:

```text
Course transcript
→ theory notes / Active Recall
→ guided Power BI implementation
→ validation evidence
→ independent audit
```

## Attribution policy

The course structure, guided case study and source dataset originate from Data with Baraa. This repository does not present those materials as independently invented.

Repository documentation is written in my own words and is intended to capture understanding, implementation decisions, validation evidence and independent reflection.

Third-party screenshots, slides or course materials should not be copied into this repository unless licensing/permission clearly allows it. Original diagrams and model screenshots created during my own implementation are preferred.

## Claim boundary

Pre-written theory notes do not mean the corresponding lesson has already been completed or mastered. Learning status is tracked separately in the repository README and in the lesson files. Practical competence claims are added only after implementation and validation evidence exists.
