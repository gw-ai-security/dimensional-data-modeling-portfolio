# Dimensional Data Modeling Portfolio

> Transforming a complex analytical source model into a clean, validated dimensional model using fact and dimension modeling, explicit grain definitions, controlled relationships, semantic measures, data-quality validation, and row-level security.

## Project Status

🚧 In Progress — Data Modeling fundamentals and guided implementation based on the Data with Baraa course.

## Objective

This repository documents my hands-on development of dimensional data modeling skills for analytics and data engineering.

The project progresses from modeling fundamentals to the redesign of a complex multi-table analytical dataset into a maintainable star/galaxy schema.

The focus is not dashboard design. The focus is on the semantic and structural layer underneath analytics:

- business understanding
- grain definition
- facts and dimensions
- keys and cardinality
- relationship design
- filter propagation
- star, snowflake and galaxy schemas
- data quality
- metric reconciliation
- row-level security
- modeling decisions and trade-offs
